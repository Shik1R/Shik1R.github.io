    VMware ubuntu虚拟机添加容量

    给vmware中ubuntu添加硬盘空间使用，同样适用挂载硬盘，留存小记。

    2018/04/25
    317字
    1 分钟
    --
    1. 命令行 vmware-vdiskmanager -x 80Gb "D:\VMware\...\..vmdk(disk address)" 添加大小或者通过UI界面直接添加
    2. reboot vmware，进入Ubuntu系统后，df -ah发现硬盘大小并未改变，要进行分区和指定文件系统，ubuntu 才能识别。
    3. fdisk -l 显示当前磁盘分区表
    4. sudo fdisk /dev/sda sda是SCSI格式硬盘，IDE类型对应hda 添加新分区 n 创建主分区 p 选择分区号 默认或者自己选择，后面自行对应 开始进行分区，注意start与end之间大小，如果第一次分得空间较小，再来一次即可。 w保存分区并退出
    5. 重启ubuntu或partprobe
    6. 格式化新分区 sudo mkfs -t ext4 /dev/sda3(名称自行对应)
    • 挂载分区 mkdir /mnt/sda3 sudo mount /dev/sda3 /mnt/sda3 手动挂载信息再/etc/mtab 中
    • 添加开机自行 sudo gedit /etc/fstab 最后一行添加/dev/sda3 /mnt/sda3 ext4 defaults, 0 1
    • 使用df -ah查看分区结果
