    GitHub Repository

    1. 创建名为name.github.io的repository
    2. 启用GitHub Pages，会显示相应网页地址。

    Hexo本地部署

    1. Reuqire
    • Node.js
    • git
    1. Windows下以下操作建议在git bash中完成。、
    • 如果 npm 下载慢，可以先检查正在使用的源。
    1

    npm config get registry

    • 安装hexo npm install -g hexo-cli

    • 检查安装是否成功 hexo -v

    • 新建一个Blog目录，如D:/Blog,在这里初始化hexo,成功时会显示“Start blogging with Hexo” hexo init

    • 体验Hexo

    1
2

      npm install 
  hexo g

    • Hexo本地服务器,地址localhost:4000,可作为测试使用 hexo s

    • 上传

    完成下一节的 Git 部署配置后，在 Blog 目录执行：

    1

    hexo d -g

    -g 为生成静态页面到 public 目录，d 为部署到 GitHub。

    Git与Hexo连接（同步推送）

    1. 设置 Git 用户名和邮箱，先把双引号里的示例值换成自己的名字和邮箱。
      1
2

      git config --global user.name "Your Name"
git config --global user.email "you@example.com"
    2. 生成秘钥

      • 密钥存储在用户目录的 ~/.ssh 下。以下使用 RSA 默认文件名；已有可用密钥可以直接使用。

      • 生成 SSH 密钥时，把示例邮箱换成自己的邮箱。

        1

        ssh-keygen -t rsa -b 4096 -C "you@example.com"

      • 把秘钥添加到ssh-agent

        1

        eval "$(ssh-agent -s)"

      • 生成的ssh key 添加到ssh-agent ssh-add ~/.ssh/id_rsa

      • 将 ~/.ssh/id_rsa.pub 中的公钥添加到 GitHub 的 Settings → SSH and GPG keys。

      • 测试是否成功 ssh -T git@github.com

      • 在 Blog 目录安装部署插件：npm install hexo-deployer-git --save。

      • _config.yml 修改如下，把两个 YOUR-USERNAME 换成自己的 GitHub 用户名。首次推送后，在仓库的 Pages 设置中选择 master 分支的根目录。

    1
2
3
4

    deploy:
  type: git
  repo: git@github.com:YOUR-USERNAME/YOUR-USERNAME.github.io.git
  branch: master

    1
2

    local_search:
  enable: true

    坑

    1. 本地能打开、部署到 GitHub Pages 后却出现 404，可以先检查链接的大小写是否和发布分支里的文件名一致。如果源文件只改了大小写，Git 没有识别到改名，可以用 git mv 先改成一个临时文件名，再改成目标名，提交后重新部署。

    杂

    1. update time 和create time 开启
    • 具体样式设置在\themes\next\layout\_macro\post-swig。
    • 在\next\_config.yml中开启同时包括其他各项设定。
